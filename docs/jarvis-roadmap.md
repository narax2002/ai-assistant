# 나만의 자비스 만들기 로드맵

## 1단계: 핵심 기능 정의

자비스가 수행할 기능의 범위와 우선순위를 정한다.

- 음성 인식
- 일정 관리
- 스마트홈 제어
- 정보 검색

## 2단계: 기술 스택

| 영역 | 기술 |
|------|------|
| 음성 인식/합성 | OpenAI Whisper(STT) + TTS API |
| 두뇌(LLM) | Claude API 또는 OpenAI API |
| 백엔드 | Python(FastAPI) 또는 Node.js |
| 프론트엔드 | React 또는 Flutter(모바일) |
| 스마트홈 | Home Assistant API |

## 3단계: 구현 순서

1. 텍스트 기반 챗봇 완성
2. 음성 입출력 추가
3. 외부 API 연동 (날씨, 뉴스, 캘린더)
4. 스마트홈 기기 제어
5. 개인화 및 습관 학습

## 4단계: 실행 환경

Raspberry Pi 또는 상시 서버에 배포하여 "헤이 자비스" 상시 대기 모드로 운영한다.
