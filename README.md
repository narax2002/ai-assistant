# AI Assistant

Personal AI assistant project bootstrap.

This repository is intended for a Discord-based assistant that can switch between local `Ollama` and cloud `Groq`, with planned Google Calendar read-only integration and easy migration to a Mac mini deployment later.

## Status

- Planning stage only
- Design notes currently live in `ai-assistant.md`
- Implementation files will be added incrementally

## Planned Stack

- Python 3.11
- `discord.py`
- OpenAI-compatible client pattern
- Ollama / Groq
- Google Calendar API
